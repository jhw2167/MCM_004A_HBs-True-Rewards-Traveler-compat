# HB's Traveler Rewards Compatibility Mod

Compatibility layer so the rewards from my main mod function well with other popular mods, particularly Waystones but also temperature and gravestone mods.

## Waystone Changes

This mod inhibits Waystones by restricting your ability to carry items with you while you teleport with them. Waystones are also unbreakable by default when using this mod.

There are two ways to travel using Waystones with items in this mod: 
- Any items that are in a Soulbound Slot will travel with you when you teleport
- If you have Blessing of the Traveler Potion Effect, all of your items will travel with you when you teleport

## Temperature Changes

Tough as Nails
- Blessing of Warm Winds - keeps the player from experiencing any cold related climate effects
- Blessing of Cool Breeze - keeps the player from experiencing any heat related climate effects

These blessings (potion effects) offer early game protection from climate effects so the player can explore freely,
and can be found in places like desert and jungle pyramids, shipwrecks and pillager forts.
